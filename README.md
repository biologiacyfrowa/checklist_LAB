# LABchecklist
Checklista do procedur laboratoryjnych
Cel projektu: stworzenie aplikacji pomagającej w pracy w laboratorium. Aplikacja będzie zawierać listę to-do, gdzie będzie można tworzyć i odhaczać poszczególne kroki konkretnej procedury laboratoryjnej. Ma ona zminimalizować pominięcie lub pomylenie kolejności etapów pracy. Ma to być pomocne narzędzie, ale nie może zastąpić dziennika laboratoryjnego.  
Funkcjonalności: wczytywanie listy kroków protokołu z pliku tekstowego lub JSON, checkbox przy każdym kroku procedury, opcjonalny timer dla etapów czasowych, zapis znacznika czasu, wskazującego kiedy dany krok został odhaczony, możliwość wgrania własnego protokołu jako szablonu
Język: Python
Format pliku tekstowego wczytywanego do aplikacji: Opis kroku | Czy timer (Tak/Nie) | Czas w sekundach
